# Campus Desk dashboard

The two SVG files are importable dashboard designs: desktop at 1280 × 900 and mobile at 390 × 948. The PNG files are previews. Both show the student view with synthetic data.

Use a dark green navigation area, pale gray page background, white cards, and plain status labels. The main action is New request. Cards summarize total/open/in-progress/resolved reports. Recent requests link to details. The mobile view stacks cards; its Menu control opens navigation containing Overview, My requests and Log out.

The staff dashboard uses the same layout, with all reports in scope. Replace My requests with All requests; add Categories; replace New request with Review requests linking to the request list. Staff do not create reports.

Typography: Arial or a matching system sans-serif. Body text 14–16 px; desktop heading 32 px; mobile heading 26 px. Primary green #1d6257; main text #172c35; background #f6f7f9. Keep visible keyboard focus and text labels alongside status colors.

The SRS defines form, loading, empty and error behavior. This design task covers the main screen only; no clickable prototype is included.

Figma: the editable desktop dashboard is saved as “Campus Desk — Student dashboard” in the supplied file, node 3:2. The mobile SVG remains a local design source. Figma URL: https://www.figma.com/design/rQ6UIsvVyf3ZrO5AecdvZU/Kevin-s-Figma-Project?node-id=3-2

Trello: https://trello.com/b/aoQSuZMB/campus-desk — a private board with ten development cards under To Do, plus Doing and Done lists. tasks.csv supplies short descriptions and a suggested two-person split. The live cards intentionally contain only short titles so the team can move and refine them.

The dashboard includes examples of staff-created categories: Transcripts, Student ID cards, IT support, Facilities and Letters. Categories are not fixed choices in application code. A transcript or ID request tracks staff work; the website does not generate official documents.
